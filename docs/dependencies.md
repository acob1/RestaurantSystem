# Dependency compatibility

Pinned baseline: Angular packages/CLI/builder **22.2.3**; TypeScript **6.0.2**; RxJS **7.8.2**; Node **24.15.0**; Tailwind/PostCSS adapter **4.1.18**; Vitest and V8 coverage **4.1.12**; jsdom **27.4.0**; Playwright **1.58.2**. Angular's official compatibility table requires Node ^24.15.0 (or supported alternatives), TypeScript >=6.0 <6.1, RxJS ^7.4.0. The 22.2.3 builder's npm peer metadata accepts Vitest ^4.0.8 and Tailwind 4. PostCSS is patched to **8.5.31** and Vite overridden to **8.3.3** for the audited build-tool advisories. Exact top-level versions plus package-lock.json pin resolved packages.

.NET target **net10.0**; SDK minimum **10.0.100**, latest-feature roll-forward within .NET 10. Docker/CI SDK baseline **10.0.403**, runtime **10.0.13**; EF Design, OpenAPI, WebApplicationFactory **10.0.13**; Npgsql EF **10.0.3**; xUnit **2.9.3**; test SDK **17.14.1**; xUnit VS runner **3.1.4**; PostgreSQL Testcontainers **4.8.1**; PostgreSQL image **17.6-alpine**; n8n CE **2.44.7**. Package lockfiles are generated by restore and enforced in CI/Docker. The SDK feature band can build the net10 target independently from package patch versions.

This is a reproducible baseline, not a declaration that older patches remain safe for production. Before production, review current advisories, update pinned SDK/runtime/dependencies deliberately and rerun the full suite. Provider SDKs for Cloudinary/Groq and Paystack adapters are not yet installed because those integrations are later phases.

Verified references on 2026-10-26: [Angular version compatibility](https://angular.dev/reference/versions), [Angular releases](https://angular.dev/reference/releases), [Npgsql EF 10.0.3](https://www.nuget.org/packages/Npgsql.EntityFrameworkCore.PostgreSQL/10.0.3), [n8n database variables](https://docs.n8n.io/hosting/configuration/environment-variables/database/). Exact npm availability and actual build results are recorded in testing.md.

Microsoft EF Design and dotnet-ef are aligned at 10.0.13. Npgsql 10.0.3 requires EF >=10.0.4 and <11; the Microsoft 10.0.13 pins satisfy this. [Microsoft EF package](https://www.nuget.org/packages/Microsoft.EntityFrameworkCore/10.0.13).
